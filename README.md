# PENERAPAN ALGORITMA K-MEANS++ MENGGUNAKAN METODE PRINCIPAL COMPONENT ANALYSIS UNTUK CLUSTERING DATA BERDIMENSI TINGGI

## Deskripsi
Project ini merupakan implementasi metode clustering menggunakan algoritma K-Means++ dengan PCA (Principal Component Analysis) sebagai reduksi dimensi.

Tujuan dari project ini adalah untuk mengelompokkan data berdasarkan kemiripan fitur serta mengurangi dimensi data agar proses clustering lebih optimal dan mudah divisualisasikan.

---

## Metode yang Digunakan
- K-Means++
- PCA (Principal Component Analysis)

---

Dataset yang digunakan tidak disertakan di repository karena ukuran file yang besar.
